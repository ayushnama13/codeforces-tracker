## Feature ideas for our tracker

1. **Public profile page with selectable visibility.** Inspired by Codolio, CodeTrace and CPBoard. Publish a read-only dashboard summary, let the owner hide selected fields, and provide a stable share URL. Data needed: Codeforces API `user.info`, `user.rating`, `user.status`; external for hosting/auth and other platforms.
2. **Exportable profile card and badges.** Inspired by Codolio Card, cf-stats, CP Insights and Codeforces Readme Stats. Generate a themed SVG/PNG featuring rating, max rating, solve count and optional activity heatmap for a README. Data needed: `user.info`, `user.rating`, `user.status`.
3. **Contest calendar with timezone and ICS export.** Inspired by CLIST, Code Calendar, ContestRadar and NextContest. Show upcoming, live and past contests in local time; export selected contests to ICS/Google Calendar. Data needed: `contest.list`; external for non-Codeforces calendars/export delivery.
4. **Contest reminders and saved events.** Inspired by CodEyes, NextContest and CP Reminder. Let the user bookmark contests and schedule configurable reminders before start. Data needed: `contest.list`; external for notification/calendar integration.
5. **Cross-platform profile connectors.** Inspired by Codolio, CodEyes, CodeTrace and DashCode. Add optional handles for other judges and show per-platform tiles alongside CF results. Data needed: external APIs/scraping; CF `user.info`, `user.rating`, `user.status` for the existing platform.
6. **Cross-platform activity calendar.** Inspired by CodeTrace and CodEyes. Combine solved/submitted days across services into one heatmap with per-platform filters. Data needed: external platform activity plus CF `user.status`.
7. **Cross-platform taxonomy normalization.** Inspired by Codolio Sheets and LogN community reports. Map equivalent tags/categories across services so a unified topic view can compare practice distribution. Data needed: external tag catalogs and mappings; CF `problemset.problems`, `user.status`.
8. **Portfolio metadata and pinned achievements.** Inspired by Codolio and CP Tracker. Allow a short bio, preferred profile links, pinned contests/problems, and selected milestones to appear in a shareable portfolio. Data needed: CF `user.info`, `user.rating`, `user.status`; external/manual profile metadata.
9. **Duplicate-aware cross-platform solve totals.** Inspired by Codolio's related-question grouping and CP Tracker's distinct-solve caveat. Show raw per-platform counts beside a deduplicated estimate, with uncertain matches marked. Data needed: external problem identity/crosswalk data and CF `problemset.problems`.
10. **Contest attendance planner and registration links.** Inspired by CLIST, Code Calendar and CodEyes. Add upcoming contest registration links, personal availability, and a planned/attended state. Data needed: `contest.list`; external registration URLs and personal calendar state.
11. **Peer or cohort leaderboard view.** Inspired by CodEyes college boards and StopStalk friend connections. Compare opted-in accounts by rating, solve volume or recent activity over the same period. Data needed: `user.info`, `user.rating`, `user.status`; external cohort/consent records.
12. **Profile freshness and source status indicators.** Inspired by CodEyes sync status and StopStalk's postmortem on stale/crawled data. Show last successful refresh, source, and whether a displayed value is cached or incomplete. Data needed: CF endpoints used by each metric plus external sync metadata.
13. **One-click portfolio export bundle.** Inspired by Codolio and Codeforces README cards. Download a Markdown snippet plus SVG card and compact JSON summary for a README or personal site. Data needed: `user.info`, `user.rating`, `user.status`; external for export hosting.
14. **Contest schedule filters and saved views.** Inspired by ContestRadar, CLIST and Codexia. Filter by platform, date, live/upcoming/past status and contest type, then save a default view. Data needed: `contest.list`; external for non-CF schedules and persistent preferences.
